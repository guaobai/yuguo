# YETIMALL 商品搬运助手

Manifest V3 浏览器插件。点击扩展图标后，它会在浏览器右侧面板中常驻显示，直到手动关闭。

用于：

1. 从 `m.yetimall.store` 商品详情链接提取商品信息、详情图片和全部 SKU。
2. 打开可配置的娱果商城商品新增页面。
3. 自动填入商品基础信息、远程图片、商品详情、价格库存和多规格数据。

插件只填写表单，不会自动点击“保存”。

## 安装

1. 先构建并部署包含商品导入桥接的 `ygcm` 前端。
2. 打开支持 Side Panel 的 Chrome 或 Edge 扩展管理页面。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择当前 `browser-extension/yetimall-product-importer` 目录。

## 使用

1. 打开插件设置，填写线上或本地的新增商品页面地址。
2. 根据后台数据填写默认分类 ID、品牌 ID 和运费模板 ID。
3. 在插件右侧面板中粘贴 YETIMALL 商品详情链接。
4. 点击“提取商品”检查提取结果。
5. 点击“自动填入”，插件会打开后台并写入商品表单，右侧插件面板保持打开。
6. 在后台检查分类、品牌、物流、图片和 SKU 后手动保存。

自动填入由扩展后台任务执行。切换标签页不会中断任务，右侧面板会实时显示填入状态；面板关闭后再次打开，也可以查看最近一次填入任务的完成状态或错误信息。

插件每次打开管理后台时都会附加一次性查询参数，避免线上前端更新后继续使用浏览器缓存中的旧页面。

## 字段映射

- 商品名称：移除来源标题开头的方括号活动标签，并限制为 64 字。
- 商品关键字：来源标签、来源商品类型、来源分站标签、YETIMALL。
- 商品简介：预售标签、商品名称、截止时间和出库时间。
- 商品封面图：来源主图 HTTPS 地址。
- 商品轮播图：主图和实际详情图。
- 商品详情：预售说明、购买提示和来源详情 HTML。
- 商品规格：按来源 SKU 的实际规格顺序提取；前两个规格名称可在插件设置中配置。
- SKU：来源 SKU 图片、价格、库存和来源 SKU ID 条码。
- 虚拟销量：可选使用来源页面销量。

当设置中启用“自动创建缺失的属性和属性值”时，自动填入过程会在后台创建缺失的规格数据，但仍不会创建或保存商品。
